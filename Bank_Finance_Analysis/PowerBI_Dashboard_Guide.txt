BANK & FINANCIAL DATA ANALYSIS PROJECT
======================================

Dataset size:
- Customers: 10,000
- Loans: 15,000
- Transactions: 50,000

Workflow:
CSV -> Excel/Power Query -> MySQL -> Python/Pandas -> Power BI

Power BI relationships:
Customers[Customer_ID] 1:* Loans[Customer_ID]
Customers[Customer_ID] 1:* Transactions[Customer_ID]

Dashboard pages:
1. Executive Overview: customers, deposits, loans, outstanding loans, default rate, failed transactions
2. Customer Analysis: city/state, income, credit score, account type, segmentation
3. Loan Analysis: loan type, approval status, interest rate, outstanding amount, defaults
4. Transaction Analysis: monthly amount, channel, transaction type, branch, status
5. Risk Analysis: credit-score bands, defaulted loans, high outstanding loans, income vs loan

DAX measures:
Total Customers = DISTINCTCOUNT(Customers[Customer_ID])
Total Deposits = SUM(Customers[Account_Balance])
Total Loan Amount = CALCULATE(SUM(Loans[Loan_Amount]), Loans[Loan_Status] <> "Rejected")
Outstanding Loans = SUM(Loans[Outstanding_Amount])
Default Rate = DIVIDE(CALCULATE(COUNTROWS(Loans),Loans[Loan_Status]="Defaulted"),COUNTROWS(Loans))
Successful Transaction Amount = CALCULATE(SUM(Transactions[Amount]),Transactions[Transaction_Status]="Success")
Failed Transaction Rate = DIVIDE(CALCULATE(COUNTROWS(Transactions),Transactions[Transaction_Status]="Failed"),COUNTROWS(Transactions))

Interview explanation:
"I worked on a banking financial data analysis project using customer, loan and transaction data.
I cleaned and validated the data using Excel and Power Query, analyzed it in MySQL using joins,
aggregations and window functions, used Python and Pandas for additional analysis and segmentation,
and created a Power BI dashboard with KPIs, loan performance, customer segmentation, transactions
and risk indicators."
